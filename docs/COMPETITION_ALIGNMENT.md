# XH-202620 榜题对应说明

## 作品定位

EvoAgent 采用“通用多智能体平台 + 学科知识包 + 真实场景工作流”结构。当前旗舰场景为教育学科研辅助：将真实教学问题依次交给课题规划、证据研究和规范核验 Agent，输出可追溯的研究方案。

## 核心功能对应

| 榜题要求 | EvoAgent 对应实现 |
| --- | --- |
| 深度贴合场景 | 教育学科研证据链示范场景与三 Agent 协作闭环 |
| 自然语言交互 | Agent 与工作流均接受自然语言任务 |
| 知识权威可信 | 学科知识库、资料来源、引用片段和人工核验 |
| 内容可追溯 | 检索结果包含标题、来源、片段编号和引用文本 |
| 复杂问题求解 | DAG 工作流与 Agent 间调用 |
| 个性化与自适应 | Agent 独立模型、提示词、Skill、知识库和进化版本 |
| 智能工作流 | Agent、工具、条件和输出节点 |
| 插件与工具 | MCP、插件 Manifest、Skills、本地工具 |
| 技术先进性 | 受控进化、对照评测、审批与回滚思想 |

## 参赛验收仍需补充的真实材料

软件工程已经提供测试与演示底座；正式参赛前，团队需要自行补齐：

1. 经过授权的教育学教材、论文、政策和研究方法资料。
2. 至少 3 个与权威答案对照的典型案例。
3. 至少 2 名教育学教师或学生的真实试用记录。
4. 准确率、引用正确率、任务耗时等量化指标。
5. 3 分钟以内从任务输入到结果输出的真实交互演示视频。
6. 伦理与安全合规声明，以及明显的 AI 生成内容标识。

榜题正文同时出现 9 月 5 日和 9 月 15 日两个提交时间，应按更严格的 2026 年 9 月 5 日倒排材料准备。
